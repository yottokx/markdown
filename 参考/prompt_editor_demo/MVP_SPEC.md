# Prompt Editor Demo — MVP仕様

## 目的

Desktop LLM本体へ組み込む前に、独立したPySide6アプリで`?`記法によるプロンプト補完の操作感を検証する。

## MVPに含めるもの

- Markdownソースを編集する単一のテキストエディタ
- Markdownシンタックスハイライト
- `?`記法のハイライトとTab補完
- リストの基本的な自動インデント
- 疑似AIによる補完
- Escによる補完キャンセル
- 補完結果を一回で戻せるUndo
- 未補完の`?`ブロック数表示
- コピーとクリア

Markdownのレンダリング表示は行わない。

## `?`記法

### 文中補完

```text
私は ?人名 です。
```

- `?`とヒントは連結する
- 前後に半角スペースを入れる。文末では後ろのスペースを省略できる
- `?ヒント`だけを、改行を含まない短い文字列へ置換する
- 記法の区切りに使用した前後の半角スペースも置換時に削除する

### 段落生成

```text
? 注意点を説明する
```

- 行頭の`?`とヒントの間に半角スペースを入れる
- ディレクティブ行全体を1段落へ置換する
- 行頭のインデントは維持する

### リスト項目の単一補完

```text
- ?注意点
```

- 末尾に`...`がなければ、現在のリスト項目を1件だけ補完する
- モデルは項目本文だけを返し、`- `とインデントはエディタが付ける

### リスト項目の複数生成

```text
- ?注意点を3つ...
```

- ヒント末尾の半角`...`が複数生成を意味する
- 件数指定がなければ3件生成する
- 元の`- `とインデントを各項目へ引き継ぐ
- 全角の`…`や、行末以外の`...`は複数生成として扱わない

## 補完対象

- 選択範囲がなければ、キャレットがある`?`ブロックを補完する
- 選択範囲があれば、範囲内に`?`がある有効なブロックをすべて補完する
- 段落とリストでは、対象行のどこにキャレットがあっても補完できる
- 不完全な記法や通常の疑問符は補完対象にしない
- コードブロック、インラインコード、URL、`\?`内の`?`は補完対象にしない

## Tabの優先順位

1. IME変換中ならIMEへ渡す
2. 選択範囲内の`?`ブロックを補完する
3. キャレット位置の`?`ブロックを補完する
4. リストをインデントする
5. キャレットが行末補完の条件を満たせば、行末までをAI補完する
6. 何もせず、タブ文字も挿入しない

Shift+Tabはリストのインデントを1段階浅くする。

リストでEnterを押した場合は、ネストを含めて前の行と同じインデントの`- `を次行へ挿入する。ネスト中はプリフィックスだけの空項目でも同じ階層を維持する。

リストプリフィックスだけの行でBackspaceを押した場合は、`- `を同じ幅の空白へ置き換え、キャレットの横位置を維持する。この行はリスト本文の継続行として扱い、Enterを押すと次行で元の階層の`- `を復元してリストを続ける。その状態でもう一度Backspaceを押すと、1段浅い階層へアウトデントして`- `を付け直す。トップレベルでは浅い階層がないため、空行にしてリストを終了する。

Windows IMEへ通知するキャレット矩形は、候補ウィンドウが入力行へ重ならないよう、表示上のキャレットより1行分下へ補正する。

## 行末補完

有効な`?`補完対象とインデント操作がない状態でTabを押すと、次の条件をすべて満たす場合だけキャレット位置へ補完文字列を挿入する。

- 選択範囲がない
- キャレットが改行または文書末尾の直前にある
- 行が空ではない
- 直前の文字がMarkdown制御文字ではない
- リストプリフィックス、見出し記号、引用記号などだけの行ではない
- フェンスコードまたはインラインコード内ではない
- 同じ行に未補完の有効な`?`記法がない

補完結果は改行を含まない文字列とし、既存の行を繰り返さずキャレット位置へ追記する。

## 補完中の動作

- 補完中であることを表示する
- Escでキャンセルする
- Tabを連打しても同じ要求を重複実行しない
- 補完中に本文が変更された場合、古い結果を適用しない
- 複数ブロックの置換は一括で行う
- 置換全体をCtrl+Z一回で元に戻せる
- 補完に失敗した場合は本文を変更しない

## 疑似AI

MVPでは実APIへ接続せず、固定結果を返す疑似AIを使用する。

疑似AIは次を再現する。

- 文中、段落、単一リスト、複数リストの補完
- 応答までの疑似遅延
- キャンセル
- 編集後に遅れて届く古い応答
- 補完失敗

## MVPに含めないもの

- Desktop LLM本体への統合
- F13+W
- 実際のAI API
- AIモードとモデル常駐
- ゴーストテキスト
- 入力停止後の自動補完
- 引用の自動インデント
- レビューと添削
- ドラフト保存
- 元アプリへの自動貼り付け
- `- `以外のリストマーカー

## 完了条件

- 独立アプリとして起動できる
- 4種類の`?`補完を疑似AIで実行できる
- 選択範囲内の複数ブロックを一括補完できる
- Tab、Shift+Tab、Esc、IMEが仕様どおり動作する
- 古い応答が編集中の本文を上書きしない
- 補完結果をCtrl+Z一回で戻せる
- ゴーストなしの操作感を実際に評価できる
