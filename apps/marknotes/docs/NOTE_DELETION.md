# 通常のノート削除

2026-09-14〜15。MarkNotesのみの追加機能。

## 操作

「ノート → ノートを削除…」、タブの右クリック、サイドバーの履歴・ピン・検索結果の右クリックから実行する。ノート名と、本文・添付を削除して取り消せないことを確認するダイアログを表示する。既定ボタンとEscはキャンセル。タイトルはプレーンテキストで表示する。

サイドバーでは右クリックしたノートを対象にし、開いている別ノートの編集位置やUndo履歴を維持する。日付見出しや余白からは削除できない。タブを閉じる操作は従来どおり別の機能。

## 保存と添付

DB内では本文、検索用本文とFTS、表示状態、ピン、添付の登録情報、タブ状態と閉じたタブ履歴を同じトランザクションで整理する。削除するノートの未保存本文を改めて保存する必要はない。ほかのノートの変更と、進行中の添付取り込みは完了を待つ。

添付の削除予定をDBへ記録してからコミットし、その後に対象UUIDのノート専用フォルダを削除する。DBの削除に失敗した場合、添付は削除せずタブも保持する。ファイルの使用中などで添付だけ削除に失敗した場合は、本文の削除を成功として扱い、残る作業を永続キューへ記録する。

削除待ちはステータスバーの「添付の削除待ち」とツールメニューから再試行でき、次回起動時にもバックグラウンドで再試行する。新しいバックアップでは削除待ちの添付を除外する。コピー元、リンク先、過去のバックアップ、書き出したファイルは変更しない。

ライブラリ形式はv2。v1からは削除待ちテーブルの追加とバージョン更新だけを同一トランザクションで行い、既存の本文を移し替えない。

## 非同期処理と画面

削除中は編集・タブ・サイドバー操作を止める。古い検索・ノート読み込み結果は世代番号で破棄し、削除後は画面の結果一覧からも直ちに取り除く。対象ノートの文書、Undo履歴、画像監視、抜粋キャッシュを解放し、残るタブへ切り替える。最後のノートを削除した場合は空画面に戻る。

## 検証方針

自動検証は `QT_QPA_PLATFORM=offscreen` で行い、デスクトップへウィンドウ、ポップアップメニュー、確認ダイアログを表示しない。`tests/conftest.py` で非表示モードを既定にした。メニューやダイアログの実行はテスト内で置き換え、構築内容とアクションを確認する。旧Markdownエディタは変更・テストしない。

この機能は通常削除であり、DB内部に残った過去のデータを消去する機能は含まない。

検証ログと配布ビルドの結果は `artifacts/note-deletion/` に保存する。
