# MarkNotes

Markdownで書き留める、ローカルのスクラップブックアプリです。ノートはアプリで管理され、入力後に自動保存されます。タブで複数のノートを切り替え、検索やピン止めで見つけ直し、画像やファイルを添付できます。

## インストールと起動

### ソースから使う

Python 3.13以上とuvを用意し、このREADMEがある `apps/marknotes` ディレクトリで実行します。初回は次のコマンドで必要なパッケージをインストールします。

```powershell
uv sync --locked
```

起動するには次を実行します。

```powershell
uv run --locked marknotes
```

リポジトリ直下からは `uv --directory apps/marknotes run --locked marknotes` で起動できます。

### Windows EXEを使う

ビルド済みの `dist/marknotes/marknotes.exe` を起動します。EXEからの起動にはPythonやuvのインストールは不要です。移動・配布する場合は `dist/marknotes/` フォルダ全体を使用してください。

## 基本操作

- **Ctrl+T / ＋**: 新しいノート。タイトル入力は不要で、本文の冒頭がタブ名になります。
- **Ctrl+W**: タブを閉じる。本文のあるノートはライブラリに残ります。未入力の新規ノートは破棄し、閉じたタブの履歴にも残しません。
- **Ctrl+Shift+T**: 閉じたタブを開く。一括で閉じたタブはまとめて復元します。閉じた履歴は直近100操作まで保持します。
- **Ctrl+Tab / Ctrl+Shift+Tab**: タブを移動。幅に収まらないタブは最終表示が古い順に「…」へ入ります。
- **ノートメニュー / タブの右クリック**: すべて閉じる、ほかのタブを閉じる、閉じたタブを開く。
- **ノートを削除…**: ノートメニュー、タブの右クリック、サイドバーのノートの右クリックから削除できます。ノート名を確認して実行すると、本文・検索索引・添付・閉じたタブの履歴から削除します。取り消しはできません。
- **ノートメニューのピン止め**: 閉じたノートもサイドバーの「ピン」から再表示できます。
- **左上のサイドバーボタン**: 履歴・ピン・検索。既定は重ね表示です。「固定」で幅を確保して表示でき、狭い画面では一時的に重ね表示へ戻ります。
- **Ctrl+Shift+F**: すべてのノートを検索。ヒットしたノートごとに検索語を強調します。1〜2文字の検索はEnterで実行します。
- **Ctrl+F**: 現在のノート内を検索。全文検索の一致には前後移動・ソース表示・検索解除もあります。
- **右上の表示切替**: ソース・プレビュー・両方。表示方法とカーソル・スクロール位置はノートごとに保持します。
- **Ctrl+V**: 画像やコピーしたファイルを添付。画像は画像記法、その他のファイルはリンクになります。

本文は入力停止後約700ms、連続入力時も最大約5秒ごとに保存します。Ctrl+Sは保留中の保存を要求します。閉じる・終了時は取り込みと保存の完了を待ちます。保存できない場合はタブを保持し、ステータスに表示します。「ツール」から保存の再試行と復旧コピーの書き出しができます。

未入力ノートの破棄は、一括で閉じる操作とアプリ終了時にも適用します。一度入力してから空にしたノート、空白・改行を入力したノート、ピン止めや添付のあるノートは保持します。

タブを切り替えてもUndo/Redoはノートごとに維持されます。タブを閉じた後と再起動後のUndo履歴は復元しません。

添付が使用中などで削除できない場合は、ステータスバーに「添付の削除待ち」を表示します。ファイルを開いているアプリを閉じて、その表示または「ツール → 添付ファイルの削除を再試行」を選んでください。次回起動時にも自動で再試行します。削除待ちの添付は、新しく作るバックアップには含めません。過去のバックアップ・書き出したファイルはそのまま残ります。

通常のノート削除は、保存ファイル内部に残る過去のデータを完全消去する機能ではありません。

## ノートと添付の保存先

Windowsでの通常の保存先は `%LOCALAPPDATA%/MarkNotes/MarkNotes/library/` です。本文と添付はこのライブラリ内にまとめて保存されます。

ノート名の変更で保存先は変わりません。添付のコピー元を後で移動しても利用できます。Undoでリンクを消した場合も添付を自動削除しません。

「ツール → ライブラリをバックアップ」で本文と添付をまとめて保存できます。「バックアップから復元」は新しいライブラリを作り、復元したライブラリへ切り替えます。「ライブラリを開く」で別の既存ライブラリも選べます。同一ライブラリの二重起動は既存ウィンドウへ引き継ぎます。

## 取り込みと書き出し

```powershell
uv run --locked marknotes "C:\Documents\メモ.md"
```

ファイル引数や「Markdownを取り込む」は、本文と相対参照のローカル添付を管理ノートに取り込みます。元のMarkdownファイルには書き戻しません。添付が見つからない場合などは確認事項をステータスに表示します。

「Markdownと添付を書き出す」で持ち出し用のフォルダを作成します。HTML/PDF出力、表・数式・Mermaid・ソース編集機能も利用できます。全文検索の対象はMarkdown本文で、添付PDFなどの内部や画像OCRは対象外です。

## Windows向けビルド

Python 3.13以上とuvを用意し、Windows上でこのREADMEがある `apps/marknotes` ディレクトリから実行します。

```powershell
uv sync --locked
uv run --locked pyinstaller --noconfirm packaging/marknotes.spec
```

生成される実行ファイルは `dist/marknotes/marknotes.exe` です。実行に必要なファイルも同じフォルダに出力されるため、移動・配布には `dist/marknotes/` フォルダ全体を使用してください。

開発・検証・設計に関する情報は [DEVELOPMENT.md](DEVELOPMENT.md) を参照してください。
