## 1. 要件整理と開発計画の作成

- Windows向けの通常のデスクトップMarkdownエディタとして、技術構成・操作仕様・段階的な実装順序を設計し、[PLAN.md](PLAN.md)に記録した。
- PySide6を採用し、左をMarkdownソース、右をQWebEngineViewのライブプレビューとする構成を決定した。
- CommonMarkを基礎に、表・取り消し線・タスクリスト等を扱う方針を整理した。
- `prompt_editor_demo`はインデント操作の仕様だけを参考にし、常駐・半透明・最前面表示などのUIは採用しなかった。
- 最初にuvプロジェクトを初期化し、左右スクロールの正常性を確認してから、編集機能・画像操作・出力へ進む順序とした。
- `.md`ファイルのパスを起動引数で受け取る方針を採用。アプリ内に関連付け設定機能は設けない。
- Mermaid・数式はレンダリングを実装し、専用エディタは追加しない方針とした。

## 2. uvプロジェクト構築と初期実装

- uvプロジェクトを初期化し、Python 3.13、PySide6、Markdown解析・変換・ハイライト等の依存関係を導入・固定した。
- `uv run md-editor`で起動できるエントリーポイントと、ファイルパス引数による文書の読み込みを実装した。
- QPlainTextEditをベースとするソースエディタ、QWebEngineViewのプレビュー、幅を変更できる左右スプリッターを実装した。
- Markdown解析・プレビュー用HTML生成・安全なHTMLの整形・ローカルリソースの読み込みを構成した。
- 行番号、ソース折り返し、スクロール同期の切り替え、先頭／末尾への移動と検証サンプルを用意した。
- 複数ファイルは、それぞれ別ウィンドウで開く構成とした。

## 3. コンテンツ位置に基づくスクロール同期

- スクロールバーの割合ではなく、Markdownのソース行とプレビュー要素の対応に基づく双方向同期を実装した。
- 見出し・段落・表の各行・コードの各行・画像などの位置を対応付けた。
- 最終行が表示上端へ来るまで、左右ともスクロールできるようにした。表示用の末尾余白はMarkdown本文や出力には追加しない。
- ホイール・スクロールバー操作、折り返し、ペイン幅変更、画像読み込み後の高さの変化を検証した。
- 数式・Mermaidの描画後や表示モード変更後にも位置を再計測し、古い更新結果の反映や同期通知の往復を防ぐ処理を追加した。
- 先頭・中央・末尾、日本語パス、空行、長い最終行などを継続して回帰検証した。

## 4. 文書の編集・保存・検索

- 新規、開く、保存、名前を付けて保存、未保存変更の確認、Undo／Redoを実装した。
- BOM・文字コード・改行コードを自動認識し、保存時の文字コード、改行形式、末尾改行の有無を保持するようにした。
- 文字コード・改行コードの変更、文字コードを指定した再読み込み、保存失敗や外部更新との競合への対応を追加した。
- ソースのMarkdownシンタックスハイライトを実装した。
- Tab／Shift+Tab、Enterによるリスト継続、空項目からの退出、2段階Backspaceを実装。番号付きリスト・タスク・引用・コードの文脈も区別した。
- 日本語IMEの変換中と通常のキー操作を区別し、絵文字を含むカーソル・選択範囲・置換位置にも対応した。
- 検索、前後の検索結果への移動、件数表示、大小文字の区別、正規表現、置換・全置換を実装した。
- ライト／ダーク／システムと同じテーマを選択できるようにした。

## 5. 貼り付け機能とコード言語の自動判定

- 通常貼り付けで、HTMLスニペットをMarkdownifyによりMarkdownへ変換する処理を実装した。
- Markdownやソースコードと判断できる場合、またはHTMLがコード表示用のラッパーである場合は、`text/plain`を優先するようにした。
- チャットUIのコピーボタン由来のHTMLが混在しても、コードやTeXへ不要なエスケープを加えないようにした。
- 「貼り付け」の直下に「形式を指定して貼り付け」サブメニューを配置した。現在の項目は以下の5つ。

  - プレーンテキストとして貼り付け
  - Markdownとして貼り付け
  - コードブロックとして貼り付け
  - 引用として貼り付け
  - 表として貼り付け

- コードブロックとしての貼り付けでは言語をオフラインで推定する。Python、JavaScript、TypeScript、JSON、HTML、CSS、SQL、シェル、C系などの特徴を検査し、曖昧な場合は言語指定なしとする。
- 本文にバッククォートが含まれていても途中で閉じないフェンスを使用する。既存のコードブロック本文への貼り付けでは、言語指定を保持し、必要に応じてフェンスを拡張する。
- 引用としての貼り付けでは空行も含めて引用記号を付け、既存のMarkdownを保持する。
- 選択範囲の置換、前後の段落分離、1回のUndoに対応した。

## 6. 画像の貼り付け・保存・編集・改名

- クリップボード画像、コピーした画像ファイル、画像ファイルの挿入に対応した。
- 画像フォルダをMarkdownの隣の`img`に固定し、`img/MD名_00001.png`等の連番名で保存・参照する処理を実装した。ファイル取り込みでは元形式を基本とする。
- Markdown未保存時は一時フォルダで画像を管理し、初回保存時に保存場所と画像名を解決するようにした。
- 別フォルダへの名前を付けて保存や、その後のUndo／Redoでも画像参照が壊れないようにした。
- ソースの画像構文を右クリックした際、現在の文書が参照する`img`配下の画像に限って編集・改名を選べるようにした。
- ラスター画像を既定のペイント、または設定した外部アプリで開く機能と、外部保存後のプレビュー更新を実装した。
- 個別改名では実ファイルとMarkdown内の参照を更新する。
- 一括改名では参照の残る画像だけを対象とし、プレフィックス・開始番号・最小桁数で変更候補を作成できるようにした。
- 既存名との衝突、共有画像、Undo履歴、途中の保存失敗を考慮し、画像改名の中断記録と画像付き復旧コピーによる復旧も実装した。

## 11. 右クリックによる書式変更

書式操作はツールバーを新設せず、選択範囲の右クリックから行う方式を検討・実装した。

| メニュー | 対応する書式 |
| --- | --- |
| 文字の書式 | 太字、斜体、取り消し線、インラインコード |
| 行・ブロックの書式 | 標準段落、見出し1〜6、引用、箇条書き、番号付きリスト、コードブロック |

- 文字書式は選択した文字を対象とし、記号込み・中身だけの選択の両方を認識する。
- 混在時は「太字に統一」「太字を解除」等を選べる。部分解除では選択外と他の書式を保持する。
- 例：`**abcdef**`の`cd`だけを太字解除すると、`**ab**cd**ef**`になる。
- インラインコードの解除は範囲全体を対象とし、本文の表示内容が変わる箇所だけエスケープする。
- ブロック操作は選択にかかる行全体を対象とし、終端が次行の先頭ならその次行を含めない。
- コード設定時は言語を自動判定し、設定後は本文だけを選択する。解除はコードブロック全体を対象とする。
- 引用・リストを含めて作用範囲が全体へ拡張する場合は、メニュー名に明示する。
- 外側の引用・リスト、子要素のインデント、前後の段落境界を保持する。
- 単一表セル・リンクの表示文字・Unicode・逆向き選択にも対応し、1回のUndoで戻せる。
- 数式・コード・URL内部や、複数行構文を途中で分断する選択など、安全に変換できない範囲では操作を無効にする。
- 変換候補の再解析で本文・他書式・リンクの整合を検証し、候補生成と行情報の再利用を改善して右クリック時の処理を高速化した。
